# Vocabulaire `rdgf:`

Contenu destiné à `https://regles.data.gouv.fr/def/rdgf#` ([ADR-0009](../decisions/ADR-0009-publication.md)). Tant que le namespace n'est pas servi, ces fichiers sont la référence.

- [context.jsonld](context.jsonld) : le contexte JSON-LD partagé par les fiches. Les énumérations `rdgf:` y sont déclarées en `@vocab`, ce qui permet d'écrire `"rdgf:factKind": "attested"` dans une fiche.
- [rdgf.ttl](rdgf.ttl) : les classes, les propriétés et les schémas de concepts SKOS avec libellés français et anglais.

Les termes et leurs valeurs sont décidés dans [decisions/](../decisions/) ; ce dossier en est la transcription.
